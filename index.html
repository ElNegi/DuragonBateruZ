ECOS DE KI — ENTREGA DEL PROYECTO ================================= Esta entrega contiene el código fuente de la versión con 402 cartas y los sistemas dinámicos añadidos. Regla base conservada: Ronda 1 = 1 dado, Ronda 2 = 2, Ronda 3 = 3, Ronda 4 = 4, Ronda 5 = 5, Ronda 6+ = 6 máximo. Para ejecutar: 1. Instala Node.js si no lo tienes. 2. Abre una terminal en esta carpeta. 3. Ejecuta: npm install 4. Ejecuta: npm run dev Para compilar: npm run build Validaciones disponibles: node scripts/validate-balance.cjs node scripts/validate-engagement.cjs Consulta MEJORAS_DINAMICAS.md, CARTAS_AMPLIADAS.md, VALIDACION_CARTAS.txt y VALIDACION_DINAMICAS.txt. Nota: node_modules y dist no se incluyen en este ZIP de entrega para evitar binarios específicos de otra plataforma y una compilación dist obsoleta. npm install los prepara correctamente en tu equipo.
