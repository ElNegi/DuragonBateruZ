# Firebase Authentication — comprobación de despliegue El código está conectado al proyecto Firebase `dragonlike-3f51d`. Para que **correo/contraseña** funcione en producción: 1. Firebase Console → Authentication → Sign-in method. 2. Habilitar **Email/Password**. 3. Authentication → Settings → Authorized domains. 4. Añadir el dominio de producción de Vercel, por ejemplo: - `duragon-bateru-z-git-main-negiel.vercel.app` - y cualquier otro dominio `*.vercel.app` concreto que realmente uses. Para que **Admin 1 / Admin 2** usen una identidad Firebase real: 1. Authentication → Sign-in method. 2. Habilitar **Anonymous**. Si Anonymous no está habilitado, los botones Admin entran automáticamente en **modo local de prueba** para que el modo solitario siga siendo usable. Ese modo local no puede acceder a Firestore/multijugador porque las reglas exigen `request.auth != null`. ## Diagnóstico desde la consola del navegador Después de cargar la web puedes ejecutar: ```js window.EcosAuth.getStatus() ``` Devuelve el usuario Firebase actual, el usuario del juego, `projectId`, `authDomain` y el host actual. También existe: ```js window.ECOS_FIREBASE_STATUS ``` para confirmar que Firebase se inicializó.
