# VERCEL DEPLOY

1. Importar el repositorio/proyecto.
2. Framework preset: **Vite** (autodetectado).
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Instalar dependencias con `npm install`.
6. Añadir el dominio de producción a Firebase Authentication → Authorized domains.

No se incluye `vercel.json` porque el proyecto no necesita configuración especial para el build Vite base.
