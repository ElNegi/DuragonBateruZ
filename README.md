# Ecos de Ki

Juego de cartas roguelike construido con React, TypeScript, Vite y Firebase. El catálogo se deriva del Word suministrado y se valida con Zod.

## Uso

Requiere Node 20 o posterior. Ejecuta `npm install`, `npm run dev`, `npm test`, `npm run validate:cards` y `npm run build`.

Consulta `FIREBASE_SETUP.md` antes de probar autenticación y guardado remoto.
